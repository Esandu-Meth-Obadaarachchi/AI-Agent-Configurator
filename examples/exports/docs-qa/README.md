# Docs Qa

Answer questions over your company PDFs and Markdown, with sources.

## The loop

- **Docs assistant** (agent): Answers questions using the company documents.  - uses: Company docs
## Run it

### With Docker (everything in one command)

```bash
cp .env.example .env      # then add your API key(s)
docker compose up --build
```

Open http://localhost:3000 for the chat, or http://localhost:8000/docs for the API.

### Locally

Needs Python 3.12+ and Node.js 20+.

```bash
make setup      # creates .env, installs dependencies
make test       # runs the test suite offline, no API key needed
make dev        # API on :8000, chat UI on :3000
```

### Try it without an API key

Set `LLM_PROVIDER=fake` in `.env`. Every step answers with a placeholder, so you can
click through the whole flow, without spending anything.

## Your documents

Put files in `backend/data/docs/`, then run `make ingest`. You can also upload files
from the chat UI. Supported: pdf, markdown.

## Configuration

All settings live in `.env` (see `.env.example`). Never commit `.env`.

- **Core backend (FastAPI + LangGraph)**: `LLM_PROVIDER`, `LLM_MODEL`, `CORS_ORIGINS`
- **Anthropic (Claude)**: `ANTHROPIC_API_KEY`, `ANTHROPIC_REFUSAL_FALLBACK`
- **pgvector (Postgres)**: `DATABASE_URL`
- **Postgres conversation memory**: `CHECKPOINTER`, `DATABASE_URL`

## Where to change things

| You want to | Edit |
| --- | --- |
| Change the loop, prompts or tools | the canvas (or `spec.json`), then regenerate |
| Override a prompt without regenerating | `backend/app/custom/prompts.py` |
| Write or fix a custom tool | `backend/app/custom/tools.py` |
| Write or fix a custom step | `backend/app/custom/nodes.py` |

Files in `backend/app/custom/` are never overwritten when you regenerate.
