# Getting started with Docs Qa

This file is a sample document. Replace it with your own files, then load them:

```
cd backend
python -m app.rag.ingest docs data/docs
```

You can also upload files from the chat UI with the paperclip button.

Supported file types: PDF, Markdown, plain text and HTML.
